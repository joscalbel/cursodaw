📖 Guía de Instalación y Despliegue

Paso a paso para clonar, configurar y ejecutar el proyecto en tu entorno local

🏠 Inicio 📖 Tutorial de Uso

1. Requisitos Previos

Antes de comenzar, asegúrate de tener instaladas las siguientes herramientas en tu ordenador:

  • Git: Control de versiones (descargar).
  • Node.js / npm: Entorno de ejecución para JavaScript (descargar).
  • Visual Studio Code: Editor de código recomendado.

2. Clonar el Repositorio e Instalación

Abre la terminal de tu sistema operativo o Git Bash y ejecuta los siguientes comandos:

1. Clonar el proyecto:

git clone https://github.com/joscalbel/cursodaw.git

2. Entrar al directorio del proyecto:

cd cursodaw

3. Instalar las dependencias necesarias:

npm install

3. Ejecución en Local

Para arrancar el servidor de desarrollo y probar la aplicación en tu navegador:

npm start

La aplicación estará disponible por defecto en la dirección: http://localhost:3000

4. Estructura de Endpoints de la API

Si estás interactuando con las rutas del backend (Servidor), puedes utilizar la siguiente referencia:

Método Ruta Descripción
GET /api/status Comprueba el estado del servidor.
GET /api/items Obtiene el listado completo de elementos.
POST /api/items Crea un nuevo elemento en la base de datos.
DELETE /api/items/:id Elimina un elemento específico por su ID.
